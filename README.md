# 🚀 PromptCraft - Маркетплейс промптов для ИИ

Веб-приложение где люди создают, делятся и находят лучшие промпты для ChatGPT, Claude и других ИИ.

## 🌟 Особенности

- ✨ Красивый интерфейс с Dark Mode
- 🔍 Поиск и фильтрация по категориям
- 💙 Система лайков
- 📝 Добавление промптов
- 📋 Копирование в буфер обмена
- 📱 Адаптивный дизайн

## 🛠️ Технический стек

- React 18
- Tailwind CSS
- Vite
- Firebase (планируется)

## 💰 Монетизация

- Google AdSense
